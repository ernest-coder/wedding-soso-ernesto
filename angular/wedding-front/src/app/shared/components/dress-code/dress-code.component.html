Dress Code

"Un mariage où l’amour est plus chaud que la raclette."

Pour Elles

Mesdames, c’est le moment de sortir vos plus belles robes de mariage. Ajoutez une touche de fourrure pour affronter le froid avec glamour, et n’oubliez pas vos chaussures à talons pour danser toute la nuit. Mais attention, si vous prévoyez de quitter la piste de danse pour une balade en montagne, une paire de chaussures adaptées et un gros manteau seront vos meilleurs alliés. Après tout, même Cendrillon aurait besoin de Moon boots à Pra-loup !

Pour Eux

Messieurs, sortez vos plus beaux costumes ! Que vous optiez pour un costume classique ou une jaquette, vous serez parfaits. N’oubliez pas vos chaussures de ville, car même dans les Alpes du Sud, le chic est de rigueur. Et si vous prévoyez de redescendre à pied, glissez une paire de chaussures adaptées dans votre sac, car personne ne veut finir comme le Petit Chaperon Rouge, égaré dans la forêt enneigée !
